Toutes les pages : rôle, sections dans l’ordre, textes, CTA, formulaires, modèles de routes, parcours. Un fichier .md par page, écrit pour l’IA qui reconstruit le site. robots.txt respecté.

    Décodage techniquestack · routes · API · sources

    Lit ce que le site publie : frameworks et versions, manifestes de build (routes cachées), endpoints API, source maps publiques (sources originales), hébergement, en-têtes de sécurité. Les routes trouvées enrichissent le scan de structure.

    Reverse engineering avancéREA · preuves locales

    Analyse approfondie en local par REA : graphe des modules JavaScript, routes et endpoints trouvés dans le code, source maps, inspection passive de la page (DOM, réseau, workers, stockage), outils WebMCP déclarés, capture de preuve. Aussi pour un fichier : bundle, source map, WASM, archive, APK, exécutable.

    L'hôte Keys_Osi n'est pas installé sur cet ordinateur. Dans le dossier de l'extension, lance une fois :

    node native-host/install.mjs

    Ouvre ce dépli pour démarrer REA.
